# 扫描阶段详解

> 标定通过后，每个新花瓶只需要做一次扫描。
> 扫描质量决定重建上限——这一步省的事，后面 10 倍补回来。

## 一、物理准备（很关键）

### 1.1 转盘改造

我们之前的失败实验告诉我们：**Kinect 看不到黑色**。

- IR 光会被黑色物体吸收，深度图返回 0
- 黑色转盘 = 一团"看不见"的圆盘 = RANSAC 找平面找到背景墙上去了

**解决**：

| 改造 | 必要性 | 用时 |
|---|---|---|
| 转盘贴一张 A3 白纸覆盖整个表面 | 必须 | 3 分钟 |
| 白纸上画十字标线（找中心用） | 推荐 | 2 分钟 |
| 白纸下垫小纸板让边缘悬空 | 可选（让 RANSAC 更稳）| 1 分钟 |

### 1.2 光照建议

- **散射光**为主（顶灯）
- **避免直射光**让花瓶产生明显阴影
- **避免反光**（地面/桌面太亮，关掉强直射光源）

### 1.3 花瓶摆放

- 居中转盘
- 离 Kinect **1.2-1.8m**（最佳深度范围）
- 花瓶高度让 Kinect **平视或略低视**

### 1.4 转盘转速

- **15-30 秒一圈**比较合适
- 太快 → 运动模糊
- 太慢 → 数据冗余、累积时间长

## 二、采集

```bash
python 03_capture_scan.py --output capture_花瓶_xxx --calib calib_imgs/calibration.json --fps 8
```

### 2.1 参数说明

- `--fps 8` — 每秒 8 帧。15 秒一圈 → 120 帧。够用。
- `--fps 10` — 想多录一些选这个
- `--fps 5` — 想轻量化（也行，60 帧已够）

### 2.2 操作流程

1. 启动 Kinect 让它热机 10 秒
2. 启动 03 脚本，**等弹出预览窗口**
3. **预览窗口的四个面板**：
   - **左上**：原始彩色（1920×1080）
   - **右上**：深度伪彩色（红=近，蓝=远）
   - **左下**：对齐 RGB（彩色映射到深度坐标系）
   - **右下**：对齐叠加（深度边缘 + 颜色），用于**实时验证对齐质量**
4. 启动转盘
5. **等转速稳定后**按 SPACE 开始录制
6. 录够 1-2 圈
7. 按 SPACE 停止
8. 程序问"几圈/几秒"，凭手感填即可

### 2.3 实时质量检查

预览窗口右下角是关键：

- **对齐 RGB 和深度边缘应该贴合**（看花瓶轮廓）
- 如果颜色和形状错开 > 2cm，**标定有问题**，停下来重新标定
- 底部信息条显示：
  - `Depth valid: XX%` — 应该 30-60%（其余是黑转盘/背景，正常）
  - `median: XXmm` — 应该和你的相机-花瓶距离一致（如 1500mm）

## 三、采集后程序会问的问题

```
请填写转盘信息：
  共转了多少圈？  → 比如 2.0
  总耗时？        → 比如 32 (秒)
```

**不需要精确**——这只是用来在 Stage 3 提供配准初值。

如果用得不准也没关系，Pose Graph 全局优化会自动找到正确位姿。

## 四、采集后的数据结构

```
capture_花瓶_xxx/
├── color/        # 原始彩色（1920×1080 BGR uint8 PNG）
│   ├── 0000.png
│   └── ...
├── depth/        # 原始深度（512×424 uint16 mm PNG）
│   ├── 0000.png
│   └── ...
├── aligned/      # ★ 对齐 RGB（512×424 BGR uint8 PNG）
│   ├── 0000.png  # 每像素对应 depth 同坐标
│   └── ...
├── timestamps.csv
└── metadata.json
```

`aligned/` 是**这套流水线的核心创新**。重建时直接读 `aligned[v, u]` 就是颜色，零对齐误差。

## 五、采集后的健康检查

如果你不确定数据是不是好的，可以用 Python 快速检查：

```bash
python -c "
import cv2, numpy as np, glob, os
files = sorted(glob.glob('capture_花瓶_xxx/depth/*.png'))
print(f'帧数: {len(files)}')
img = cv2.imread(files[0], cv2.IMREAD_UNCHANGED)
print(f'格式: dtype={img.dtype}, shape={img.shape}')
d = img.astype(float)
d[d==0] = np.nan
print(f'中位深度: {np.nanmedian(d):.0f}mm, 有效像素: {np.count_nonzero(~np.isnan(d))/d.size*100:.1f}%')
"
```

会告诉你：
- 帧总数
- 深度图格式是否正确（uint16, 512×424）
- 中位深度和有效像素比例

**判断标准**：

| 指标 | 正常值 | 异常处理 |
|---|---|---|
| 帧数 | 一圈 120+ 帧 | 太少：录久点 |
| 中位深度 | 1200-1800mm | 太近/太远：调相机位置 |
| 有效像素 | 30-60% | < 20%：太多黑色物体；> 80%：太空旷 |
| 格式 | uint16 1ch | 8-bit/3ch：数据损坏，重录 |

## 六、典型的扫描场景

### 标准场景（推荐）

- 距离：1.5m
- 转速：22 秒一圈
- FPS：8
- 录 2 圈 = 44 秒 = ~350 帧

### 快速场景

- 距离：1.2m
- 转速：15 秒一圈
- FPS：8
- 录 1 圈 = 120 帧

### 高密度场景

- 距离：1.5m
- 转速：30 秒一圈
- FPS：10
- 录 2 圈 = 600 帧（Stage 1 抽 36 帧用即可）

## 七、扫描质量自检清单

录完后，**先打开 aligned/0000.png 看一眼**：

- [ ] 花瓶+植物清晰可见
- [ ] 没有大面积黑色（除了转盘）
- [ ] 颜色对得上（不是错位的）
- [ ] 边缘没有强光过曝

任何一项不满足，**别浪费时间继续往下做**——回到这一步重做。
